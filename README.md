# React Accordion

A reusable Accordion component built with React and Tailwind CSS.

## Features

- Single-selection mode
- Multi-selection mode
- Expand/collapse questions
- Data-driven rendering
- Responsive UI

## Tech Stack

- React
- Tailwind CSS
- Vite

## Concepts Practiced

- useState
- Event handling
- Conditional rendering
- Array manipulation
- Rendering lists with map()
